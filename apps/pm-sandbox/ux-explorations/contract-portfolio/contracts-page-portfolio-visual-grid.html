How this replaces the current three large visuals

The grid gives leaders the same visual grammar across all measures: population scale, value capture, and cost pressure.

In the live Contracts page, each chart could become clickable. Selecting a market, contract type, segment, or payor would filter the agreements table below and preserve the current drilldown path into Agreement and Contract Scorecards.
