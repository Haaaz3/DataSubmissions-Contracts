Pros / Cons / Reasoning

Pros

  • Beautiful, scannable pattern for many KPIs across domains.
  • Shows where financial exposure is concentrated without opening every card.
  • Works well for executive huddles and portfolio triage.

Cons

  • Color meaning must be clearly defined.
  • Not ideal for explaining detailed tier economics.
  • May need accessibility alternatives beyond color.

Reasoning

  • The current stacked view hides cross-domain hotspots.
  • Financial leaders can use this to ask targeted follow-up questions.
  • Best as a summary layer above detailed KPI drilldowns.
