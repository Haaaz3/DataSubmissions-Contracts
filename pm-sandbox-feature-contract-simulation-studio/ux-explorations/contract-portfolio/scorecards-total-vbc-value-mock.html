Annualized Cost

Spend context

This is not value earned. It is current medical cost under management: current PMPM × lives × 12.

Total Earned VBC Value

Settlement + incentives

This is the primary earned value metric if incentives are separate from the shared savings settlement.

Total Potential VBC Value

Max settlement + potential incentives

This is the denominator for VBC capture rate and should be auditable from contract terms.

Implementation implication

If the live app adds Total Earned VBC Value and Total Potential VBC Value, it should also store whether quality incentives are separate, embedded as settlement modifiers, or hybrid. Otherwise, Settlement + Incentives could accidentally double count for contracts where quality dollars are already embedded in settlement.
